# Implementation Roadmap

## 0. 실제 적용 경로

```text
기존 앱 루트: D:\Project\veritas-bible-android\
설계 문서 위치: D:\Project\veritas-bible-android\docs\inductive_bible_study_design_bundle
```

로드맵은 기존 앱을 보존하면서 귀납적 성경연구 모듈을 3개의 Goal로 통합하는 방식으로 진행합니다.


## 1. 전제

기존 성경앱의 읽기/메모 구조가 이미 있다는 가정하에, 기존 구조를 최대한 유지하면서 귀납적 연구 워크벤치를 추가합니다.

기술스택은 실제 레포 확인 후 결정합니다. 에이전트는 기술스택을 임의로 바꾸지 않습니다.

---

## 2. Phase 1: 기반 안정화

목표: 기존 앱의 성경 읽기/메모 구조 위에 연구 세션 도메인을 추가할 수 있는 기반을 만든다.

작업:

- 기존 성경 본문 데이터 구조 파악
- 기존 메모/북마크 저장 방식 파악
- 연구 세션 테이블/모델 추가
- 연구 단계 enum 추가
- 자동 저장 구조 설계
- 마이그레이션 추가
- 연구 세션 목록 화면 추가
- 본문에서 연구 세션 생성 흐름 추가

완료 기준:

- 본문 범위로 연구 세션을 생성할 수 있다.
- 앱 재시작 후 연구 세션이 유지된다.
- 기존 메모 기능이 깨지지 않는다.

---

## 3. Phase 2: 마킹/구조 분석

목표: 귀납적 연구의 핵심인 본문 마킹과 주어-동사 연결 기능을 구현한다.

작업:

- 텍스트 범위 선택
- 마킹 타입 저장
- 마킹 렌더링
- 마킹 편집/삭제
- 주어-동사 연결 모델
- 연결선 렌더링
- 연결선 필터
- 구조만 보기

완료 기준:

- 주어/동사/접속사 마킹 가능
- 주어-동사 연결 가능
- 연결 정보가 저장/복원됨
- 연결선이 많아도 필터로 관리 가능

---

## 4. Phase 3: 연구 워크플로우

목표: 관찰, 성격 규정, 단락 분해, 해석, 핵심주제, 명제, 적용을 단계별로 구현한다.

작업:

- 단계별 입력 패널
- 관찰 질문 템플릿
- 성격 태그
- 단락 나누기
- 단락 제목
- 해석 노트
- 핵심주제 후보
- 명제 작성
- 개요 작성
- 적용 작성
- 단계 완료 체크

완료 기준:

- 사용자가 한 본문에 대해 전체 연구 흐름을 완료할 수 있다.
- 각 단계 데이터가 독립적으로 저장된다.
- 핵심주제와 단락/마킹/해석 근거가 연결된다.

---

## 5. Phase 4: 검색/출력/백업

목표: 출시 품질에 필요한 데이터 재사용성과 보존성을 확보한다.

작업:

- 연구 세션 검색
- 태그 검색
- 본문 범위 필터
- Markdown 출력
- PDF 출력
- JSON/ZIP 백업
- 가져오기
- 충돌 처리
- 리포트 템플릿

완료 기준:

- 연구 결과를 외부 파일로 보관할 수 있다.
- 백업 후 복원할 수 있다.
- 연구 데이터가 장기 보존 가능한 형태를 갖춘다.

---

## 6. Phase 5: 훈련/리더/품질

목표: 개인 연구 앱을 넘어 실제 교회 훈련 환경에서 사용할 수 있게 한다.

작업:

- 연구 품질 체크리스트
- 모범 연구 템플릿
- 리더 피드백 코멘트
- 연구 진행도
- 훈련 과제
- 도움말/온보딩
- 접근성 강화
- 다국어 리소스 정리

완료 기준:

- 초보자도 연구 흐름을 따라갈 수 있다.
- 리더가 연구 결과를 검토할 수 있다.
- 앱 출시 전 QA 체크리스트를 통과한다.

---

별도 승인 후 진행합니다.

- 계정/동기화
- 교회 그룹 서버
- 외부 성경 API
- 원어 사전 API
- 상용 주석 라이선스 연동
