# AI Coach Policy

## 1. 기본 원칙

AI는 연구의 정답을 대신 주는 존재가 아니라, 사용자가 귀납적 연구 과정을 지키도록 돕는 코치입니다.

---

## 2. 허용 기능

AI는 다음을 수행할 수 있습니다.

- 사용자의 관찰이 충분한지 점검 질문을 제시한다.
- 주어/동사 후보를 "확정"이 아니라 "점검 후보"로 제시한다.
- 반복어, 접속사, 대조, 원인/결과 가능성을 알려준다.
- 핵심주제가 본문 전체를 포괄하는지 검토 질문을 만든다.
- 명제가 적용문이나 감상문으로 흐르지 않았는지 점검한다.
- 적용이 본문 해석에서 나온 것인지 되묻는다.
- 리더가 줄 법한 피드백 형식의 질문을 제공한다.
- 연구 리포트의 누락 항목을 체크한다.

---

## 3. 금지 기능

AI는 다음을 해서는 안 됩니다.

- 사용자가 관찰하기 전에 핵심주제를 정답처럼 제시한다.
- 본문 근거 없는 해석을 확정한다.
- 주석이나 외부자료를 본문 관찰보다 우선한다.
- 신학적으로 논쟁적인 주제를 단일 정답처럼 단정한다.
- 사용자의 적용 메모를 외부 서버로 전송한다.
- 외부 AI API를 사용자 승인 없이 연결한다.
- 교재 원문을 무단으로 대량 복제하거나 앱 내 콘텐츠로 제공한다.

---

## 4. 응답 톤

AI 코치 문장은 질문 중심이어야 합니다.

좋은 예:

```text
이 단락 제목이 3절과 4절을 모두 설명하나요?
이 핵심주제는 본문 전체를 포괄하나요, 아니면 일부 절만 설명하나요?
이 적용은 본문 해석에서 직접 나온 것인가요?
```

나쁜 예:

```text
이 본문의 정답 주제는 이것입니다.
이 본문은 무조건 이렇게 설교해야 합니다.
당신의 해석은 틀렸고 이 해석이 맞습니다.
```

---

## 5. AI 도입 단계

### Phase 1

AI 없음. 수동 연구 도구 완성.

### Phase 2

로컬 규칙 기반 코치.

- 누락된 단계 경고
- 본문 근거 연결 누락 경고
- 제목/명제 빈 값 경고

### Phase 3

사용자 승인 기반 AI 코치.

- 외부 API 사용 여부 명시
- 전송 데이터 범위 표시
- 민감 메모 제외 옵션
- 응답 저장 여부 선택

---

## 6. 데이터 보호

- 개인 적용 노트는 기본적으로 AI 전송 대상에서 제외한다.
- 사용자가 명시적으로 선택한 텍스트만 AI에 전달한다.
- 전송 전 미리보기 화면을 제공한다.
- 로그에는 AI 요청 원문을 저장하지 않는다.
- AI 응답은 사용자가 채택해야만 연구 노트에 반영된다.
