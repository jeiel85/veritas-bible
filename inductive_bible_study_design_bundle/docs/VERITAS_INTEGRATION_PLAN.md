# Veritas Integration Plan

## 1. 실제 프로젝트 경로

```text
기존 앱 루트:
D:\Project\veritas-bible-android\

귀납적 성경연구 설계 문서:
D:\Project\veritas-bible-android\docs\inductive_bible_study_design_bundle
```

## 2. 통합 원칙

이 작업은 새 앱을 만드는 것이 아니라 기존 성경앱에 연구 모듈을 추가하는 작업입니다.

기존 앱의 현재 수준은 다음으로 가정합니다.

- 성경 읽기 가능
- 일반 메모 가능
- 읽기 계획 가능
- 읽기 진행률 확인 가능
- 기존 시중 성경앱과 큰 차이는 아직 없음

귀납적 성경연구 기능은 기존 메모 기능을 조금 확장하는 수준이 아니라, 별도의 연구 세션과 연구 단계, 본문 마킹, 구조 분석, 핵심주제, 명제, 개요, 적용, 내보내기까지 포함하는 연구 워크벤치입니다.

## 3. 절대 보존해야 할 기존 기능

- 성경 본문 표시
- 성경 탐색과 검색
- 기존 메모 생성/수정/삭제
- 읽기 계획
- 읽기 진행률
- 기존 로컬 데이터
- 기존 앱 패키지명, 네임스페이스, 테마, 네비게이션 원칙

## 4. 새로 추가할 도메인

기존 메모 기능과 연구 노트 기능은 분리합니다.

```text
기존 Memo
- 빠른 메모
- 개인 기록
- 본문별 간단한 생각

StudySession
- 본문 범위 기반 연구
- 단계형 연구 진행
- 관찰/구조/성격/해석/핵심주제/명제/개요/적용
- 연구 결과 내보내기
```

## 5. Goal 분할 이유

귀납적 성경연구 기능을 한 번에 모두 구현하면 기존 앱의 DB, UI, 상태 관리, 네비게이션을 크게 흔들 가능성이 큽니다. 따라서 다음 세 단계로 나눕니다.

| Goal | 목적 | 완료 상태 |
|---|---|---|
| Goal 1 | 기존 앱에 연구 세션 기반을 안전하게 붙임 | 연구 세션 생성/목록/상세/기본 노트 저장 가능 |
| Goal 2 | 귀납적 연구다운 본문 관찰 도구 추가 | 본문 마킹, 주어-동사 연결, 성격 태그 가능 |
| Goal 3 | 연구 결과 완성 흐름 구현 | 해석/명제/개요/적용/Markdown 내보내기 가능 |

## 6. 첫 구현의 성공 기준

Goal 1이 끝났을 때 성공 기준은 다음입니다.

- 기존 성경 읽기, 메모, 읽기 계획, 진행률 기능이 깨지지 않는다.
- 성경 본문에서 연구 세션을 시작할 수 있다.
- 연구 세션 목록이 보인다.
- 연구 세션 상세 화면에서 선택 본문이 보인다.
- 관찰, 단락 구분, 핵심주제, 적용을 저장할 수 있다.
- 앱 재시작 후 연구 데이터가 유지된다.
- 필요한 마이그레이션이 데이터 손실 없이 동작한다.
- README, CHANGELOG, HISTORY, DECISION_LOG가 갱신된다.

## 7. 에이전트에게 금지할 작업

- 기존 앱 전면 재작성
- 기술스택 임의 변경
- 기존 DB 삭제
- 기존 메모를 연구 노트로 강제 변환
- 외부 AI API 추가
- 로그인/클라우드 동기화 추가
- 분석/광고 SDK 추가
- 성경 번역본 데이터 임의 추가
- 패키지명/네임스페이스 임의 변경
- 파괴적 Git 명령 실행
