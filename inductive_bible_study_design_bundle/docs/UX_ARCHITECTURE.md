# UX Architecture

## 1. 핵심 UX 원칙

- 사용자가 처음부터 모든 도구를 보지 않게 한다.
- 연구 단계에 맞는 도구만 우선 노출한다.
- 본문은 항상 중심에 둔다.
- 기록은 끊기지 않아야 한다.
- 마킹, 구조, 노트는 서로 연결되어야 한다.
- 사용자는 언제든지 "왜 이 결론이 나왔는지" 본문 근거로 돌아갈 수 있어야 한다.

---

## 2. 기본 내비게이션

```text
성경
연구
노트
훈련
자료
설정
```

### 성경

- 읽기
- 검색
- 기본 메모
- 연구 시작

### 연구

- 연구 세션 목록
- 진행 중 연구
- 완료 연구
- 연구 유형 필터

### 노트

- 전체 메모
- 관찰/해석/적용 필터
- 태그 검색

### 훈련

- 귀납적 연구 방법 도움말
- 예제 연구
- 체크리스트
- 연습 과제

### 자료

- 관주
- 배경자료
- 사용자 자료
- 라이선스 정보

### 설정

- 글자 크기
- 테마
- 백업/복원
- 개인정보
- 앱 정보

## 3. 모바일 연구 화면

```text
상단: 본문 범위 / 단계 / 저장 상태
본문: 성경 텍스트 + 마킹 레이어
하단: 단계별 입력 패널
플로팅: 마킹 도구 / 구조 도구
```

### 하단 패널 모드

- 준비
- 관찰
- 구조
- 성격
- 단락
- 해석
- 주제
- 명제
- 개요
- 적용

## 5. 텍스트 선택 UX

선택 후 메뉴:

```text
주어 | 동사 | 목적어 | 접속사 | 핵심어 | 원인 | 결과 | 대조 | 더보기
```

더보기:

```text
명령 | 요청 | 설명 | 근거 | 목적 | 조건 | 반복어 | 적용 단서
```

## 6. 연결선 UX

1. 사용자가 첫 번째 마킹을 선택한다.
2. `연결 시작`을 누른다.
3. 두 번째 마킹을 선택한다.
4. 연결 타입을 고른다.
5. 앱이 연결선을 표시한다.

연결선은 본문 보기에서 복잡해질 수 있으므로 다음 필터가 필요하다.

- 전체 보기
- 주어-동사만 보기
- 원인-결과만 보기
- 대조만 보기
- 핵심주제 근거만 보기
- 연결선 숨기기

---

## 7. 단계별 도움말

각 단계에는 짧은 질문형 도움말을 둔다.

예:

관찰 단계:

- 반복되는 단어가 있나요?
- 누가 무엇을 하나요?
- 접속사가 흐름을 바꾸나요?
- 명령, 설명, 사건 서술 중 어떤 말투인가요?

해석 단계:

- 이 단어는 문맥 안에서 어떤 의미인가요?
- 본문 전체 주제와 어떻게 연결되나요?
- 이 해석의 본문 근거는 무엇인가요?

적용 단계:

- 본문이 보여준 진리는 무엇인가요?
- 내 삶에서 비춰야 할 부분은 무엇인가요?
- 무엇을 조정해야 하나요?

---

## 8. 온보딩

첫 실행 시 3단계 온보딩을 제공한다.

1. 일반 메모와 귀납적 연구의 차이
2. 본문 마킹과 주어-동사 연결 방법
3. 핵심주제와 적용 작성 방법

온보딩은 다시 볼 수 있어야 한다.
