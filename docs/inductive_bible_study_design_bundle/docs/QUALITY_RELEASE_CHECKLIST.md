# Quality and Release Checklist

## 1. 출시 전 필수 검증

### 1.1 핵심 플로우

- [ ] 본문을 탐색할 수 있다.
- [ ] 본문 범위를 선택해 연구 세션을 만들 수 있다.
- [ ] 연구 세션이 자동 저장된다.
- [ ] 주어/동사/접속사를 마킹할 수 있다.
- [ ] 주어-동사 연결선을 만들 수 있다.
- [ ] 단락을 나눌 수 있다.
- [ ] 단락 제목을 붙일 수 있다.
- [ ] 핵심주제를 작성할 수 있다.
- [ ] 명제를 작성할 수 있다.
- [ ] 적용을 작성할 수 있다.
- [ ] 연구 리포트를 내보낼 수 있다.
- [ ] 앱 재시작 후 데이터가 유지된다.
- [ ] 백업과 복원이 가능하다.

---

## 2. 데이터 검증

- [ ] DB 마이그레이션 테스트가 있다.
- [ ] 백업 JSON에 schemaVersion이 있다.
- [ ] 가져오기 중 중복 세션 처리가 있다.
- [ ] 삭제 전 확인이 있다.
- [ ] 자동 저장 중 충돌 방지 로직이 있다.
- [ ] 연구 데이터가 로그에 노출되지 않는다.

---

## 3. UI/UX 검증

- [ ] 빈 상태 화면이 있다.
- [ ] 오류 상태 화면이 있다.
- [ ] 로딩 상태 화면이 있다.
- [ ] 오프라인 상태 안내가 있다.
- [ ] 다크 모드가 있다.
- [ ] 글자 크기 조절이 가능하다.
- [ ] 터치 영역이 충분하다.
- [ ] 긴 본문에서도 마킹 UX가 유지된다.
- [ ] 연결선이 많을 때 필터링할 수 있다.

---

## 4. 접근성

- [ ] 주요 버튼에 접근성 라벨이 있다.
- [ ] 본문 글자 크기 조정이 가능하다.
- [ ] 색상만으로 의미를 구분하지 않는다.
- [ ] 고대비 환경에서도 주요 기능을 사용할 수 있다.
- [ ] 키보드/마우스 입력을 고려한다.

---

## 5. 국제화

- [ ] 한국어 문자열이 리소스화되어 있다.
- [ ] 영어 문자열이 리소스화되어 있다.
- [ ] 하드코딩된 사용자 노출 문구가 없다.
- [ ] 날짜/시간 형식이 로케일을 따른다.

---

## 6. 성능

- [ ] 긴 장 본문에서 스크롤이 부드럽다.
- [ ] 마킹 500개 이상 연구 세션도 열 수 있다.
- [ ] 연구 세션 목록 검색이 지연 없이 동작한다.
- [ ] PDF/Markdown 출력 중 UI가 멈추지 않는다.

---

## 7. 보안/개인정보

- [ ] 민감한 적용 메모가 로그에 남지 않는다.
- [ ] 백업 파일에 민감 정보 포함 가능성이 안내된다.
- [ ] 외부 전송 기능은 기본 비활성화되어 있다.
- [ ] API 키/토큰이 저장소에 없다.
- [ ] 사용자 데이터 삭제는 명시적 확인이 필요하다.

---

## 8. 빌드/릴리즈

- [ ] debug 빌드 성공
- [ ] release 빌드 성공
- [ ] 테스트 실행 결과 기록
- [ ] 린트 또는 정적 검사 실행
- [ ] 버전명/버전코드 확인
- [ ] CHANGELOG 갱신
- [ ] HISTORY 갱신
- [ ] 릴리즈 노트 작성
- [ ] APK/AAB 산출물 확인
- [ ] mapping/symbols 산출물 확인
- [ ] 태그 버전과 앱 버전 일치

---

## 9. 스토어 제출 전 확인

- [ ] 앱 이름 확정
- [ ] 패키지명 확정
- [ ] 앱 아이콘
- [ ] 스크린샷
- [ ] 개인정보 처리방침
- [ ] 데이터 수집/전송 여부 설명
- [ ] 성경 번역본/자료 라이선스 확인
- [ ] 테스트 계정 필요 여부 확인
- [ ] 알려진 문제 문서화
