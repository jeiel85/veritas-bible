# Veritas Bible Android - Inductive Study Design Bundle

이 설계 묶음은 기존 Android 성경앱 `D:\Project\veritas-bible-android\`에 **귀납적 성경연구 워크벤치** 기능을 출시 가능한 품질로 통합하기 위한 문서입니다.

사용자가 추가 설계 문서를 배치한 실제 경로는 다음입니다.

```text
D:\Project\veritas-bible-android\docs\inductive_bible_study_design_bundle
```

기존 앱은 이미 성경 읽기, 메모, 읽기 계획, 읽기 진행률 확인 기능을 갖고 있으므로, 이 묶음의 목표는 새 앱을 처음부터 만드는 것이 아니라 **기존 성경앱에 연구 모듈을 안전하게 추가**하는 것입니다.

---

## 빠른 사용 순서

에이전트 코딩 도구에는 한 번에 전체를 요구하지 말고 아래 순서로 `/goal`을 나누어 요청합니다.

1. `Goal 1` — 기존 앱에 연구 세션 기반을 통합합니다.
2. `Goal 2` — 본문 마킹과 주어-동사 구조 분석을 구현합니다.
3. `Goal 3` — 해석, 명제, 개요, 적용, Markdown 내보내기를 완성합니다.

상세 프롬프트는 다음 파일에 있습니다.

```text
docs/GOAL_PROMPTS.md
docs/GOAL_01_BASE_INTEGRATION.md
docs/GOAL_02_MARKUP_STRUCTURE.md
docs/GOAL_03_INTERPRETATION_EXPORT.md
docs/VERITAS_INTEGRATION_PLAN.md
```

# Inductive Bible Study App

귀납적 성경연구 방식에 특화된 성경 연구 앱 설계 문서입니다.

이 프로젝트는 단순한 성경 읽기 앱이나 메모 앱이 아니라, 사용자가 성경 본문을 직접 관찰하고, 구조를 분석하고, 핵심주제와 적용을 도출하도록 돕는 **성경연구 워크벤치**를 목표로 합니다.

> 현재 프로젝트명과 패키지명은 임시값입니다. 기존 앱에 통합하는 경우 기존 앱 이름, 패키지명, DB 구조, 기술스택을 우선 유지합니다.

---

## 1. 제품 한 문장 정의

**성경 본문을 메모하는 앱이 아니라, 본문을 관찰하고 구조화하여 핵심주제와 적용까지 도출하도록 돕는 귀납적 성경연구 워크벤치.**

---

## 2. 문제 정의

기존 성경앱은 대체로 다음 기능에 집중합니다.

- 성경 본문 읽기
- 밑줄, 형광펜, 북마크
- 자유 메모
- 검색
- 읽기표

그러나 귀납적 성경연구 방식에는 다음 작업이 필요합니다.

- 본문 범위 지정
- 배경과 문맥 확인
- 주어, 동사, 목적어, 접속사 표시
- 단어와 문장 구조 관찰
- 성격 규정
- 단락 나누기
- 단락 제목 붙이기
- 핵심주제 도출
- 핵심주제의 본문 근거 검증
- 명제화
- 개요화
- 적용
- 리더 피드백
- 연구 결과 출력과 공유

일반 메모 기능만으로는 위 흐름을 안정적으로 수행하기 어렵습니다.

---

## 3. 제품 목표

### 3.1 사용자 목표

사용자가 다음을 할 수 있어야 합니다.

- 성경 본문을 읽는 데서 멈추지 않고 연구 세션으로 전환한다.
- 연구 단계를 따라 본문을 관찰하고 해석한다.
- 본문 위에 문법/구조 마킹을 한다.
- 주어와 동사를 연결하고, 구조를 시각적으로 확인한다.
- 단락을 나누고 각 단락의 제목과 성격을 기록한다.
- 본문 전체를 포괄하는 핵심주제를 작성한다.
- 핵심주제를 명제와 개요로 정리한다.
- 본문에서 나온 적용을 일인칭으로 기록한다.
- 자신의 연구 결과를 다시 열고, 수정하고, 출력하고, 공유한다.
- 리더나 그룹원에게 피드백을 받을 수 있다.

### 3.2 제품 품질 목표

이 프로젝트는 MVP가 아니라 실제 출시 가능한 수준을 목표로 합니다.

필수 품질 기준:

- 로컬 우선 저장
- 오프라인 사용 가능
- 연구 데이터 자동 저장
- 앱 재시작 후 모든 연구 상태 복원
- 백업/복원 또는 내보내기/가져오기
- 다크 모드
- 접근성 기본 대응
- 한국어/영어 문자열 리소스 분리
- 릴리즈 빌드 검증
- 데이터 마이그레이션 전략
- 개인정보/민감 메모 보호
- 도움말/온보딩 포함
- 오류/빈 상태/로딩 상태 설계

---

## 4. 핵심 연구 흐름

```text
본문 선택
→ 준비
→ 관찰
→ 구조 분석
→ 성격 규정
→ 단락 분해
→ 해석
→ 핵심주제
→ 명제화
→ 개요화
→ 적용
→ 리포트/공유/지도
```

각 단계는 단순 화면이 아니라 독립적인 데이터 모델과 검증 기준을 가져야 합니다.

## 5. 주요 기능

### 5.1 성경 읽기

- 책/장/절 탐색
- 본문 검색
- 기본 메모
- 북마크
- 읽기 기록
- 연구 세션으로 전환

### 5.2 연구 세션

- 본문 범위 기반 연구 세션 생성
- 연구 유형 선택
  - 단락 연구
  - 장 연구
  - 책별 연구
  - 주제별 연구
  - 인물 연구
  - 예언 연구
- 자동 저장
- 진행 단계 표시
- 완료율 표시
- 연구 품질 체크리스트

### 5.3 본문 마킹

- 주어
- 동사
- 목적어
- 접속사
- 반복어
- 핵심어
- 명령
- 이유
- 원인
- 결과
- 대조
- 목적
- 조건
- 근거
- 적용 단서

### 5.4 구조 연결

- 주어-동사 연결
- 원인-결과 연결
- 대조 연결
- 설명-근거 연결
- 핵심주제-단락 연결
- 연결선 숨김/표시
- 구조만 보기

### 5.5 성격 규정

본문의 단어, 어구, 문장, 단락이 주제에 대해 어떤 성격을 갖는지 태그화합니다.

기본 성격 태그:

- 정의
- 의미
- 이유
- 원인
- 결과
- 현상
- 단계
- 영역
- 측면
- 근거
- 특징
- 특성
- 목적
- 조건
- 과정
- 관계
- 방법
- 행위
- 적용

### 5.6 단락 분해

- 본문 범위 안에서 단락 생성
- 절 단위 또는 문장 단위 범위 지정
- 단락 제목
- 단락 요약
- 단락 성격
- 전체 주제와의 관계
- 단락 순서 변경
- 단락별 마킹/노트 필터

### 5.7 해석 워크벤치

- 핵심 단어 해석
- 문장 해석
- 단락 해석
- 문맥 메모
- 병행 구절
- 관주
- 해석 근거
- 주의 사항
- 사용자의 추론과 본문 근거 구분

### 5.8 핵심주제 도출

- 핵심주제 후보 작성
- 본문 근거 연결
- 단락별 지지 여부 확인
- 주제 문장 정교화
- 핵심주제 최종 확정

### 5.9 명제화

- 핵심주제를 명확한 문장으로 변환
- 본문 근거 연결
- 참/거짓을 판단할 수 있는 문장인지 점검
- 적용과 혼동되지 않도록 검증

### 5.10 개요화

- 대지/소지 구조
- 단락 기반 자동 초안
- 사용자가 직접 수정
- 본문 근거 표시
- 설교/나눔/교안용 출력

### 5.11 적용

- 본문이 보여주는 진리
- 내 삶을 비추는 거울화
- 조정해야 할 부분
- 구체적 실천
- 점검 날짜
- 적용 완료 체크

### 5.12 그룹/리더 기능

초기 출시에서는 로컬 공유 또는 파일 기반 공유를 우선합니다. 계정/서버 기반 그룹 기능은 별도 승인 후 진행합니다.

- 연구 리포트 공유
- 피드백 코멘트
- 리더 검토 상태
- 연구 훈련 체크리스트
- 모범 연구 템플릿

### 5.13 출력/백업

- Markdown 내보내기
- PDF 내보내기
- JSON 백업
- ZIP 백업
- 가져오기
- 연구 세션 복제
