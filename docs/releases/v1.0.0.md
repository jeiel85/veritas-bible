## v1.0.0 — Android 리뉴얼 이관

### 핵심 변경

Veritas Bible을 기존 Flutter 프로젝트에서 Android/Kotlin Compose 기반 리뉴얼 앱으로 전환했습니다. 리뉴얼 프로젝트의 주요 화면, Room 기반 로컬 데이터 구조, Material 3 UI를 현재 저장소에 이관했습니다.

### 변경 사항

- 기존 Flutter, iOS, Web, Desktop 구조 제거
- Android 네이티브 Gradle 프로젝트 구조 적용
- 온보딩, 대시보드, 성경 리더, 검색, 노트, 설정 화면 반영
- Gradle Wrapper 추가로 명령줄 빌드 재현 가능
- 릴리즈 문서와 Play Console 노트를 태그 버전과 함께 관리하도록 정비

### 검증

- `.\gradlew.bat assembleDebug`
- `.\gradlew.bat testDebugUnitTest`

### 다운로드

- Play Store 업로드용: `veritas-bible-release.aab`
- Android APK: `veritas-bible-release.apk`
