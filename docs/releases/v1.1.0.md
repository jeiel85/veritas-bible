## v1.1.0 — 귀납적 성경연구 워크벤치

### 핵심 변경

기존 성경 읽기·메모 앱에 **귀납적 성경연구 워크벤치**가 통합되었습니다. 본문에서 한 번에 연구 세션을 만들고, 9단계(관찰 → 마킹/구조 → 단락 → 해석 → 핵심주제 → 명제 → 개요 → 적용 → 리포트)를 따라 완성한 결과를 Markdown · PDF · 시스템 인쇄로 공유할 수 있습니다.

### 신규 기능

- 하단 네비게이션에 **‘성경연구’ 탭** 추가. 기존 5개 탭(성경읽기/검색/통계분석/연구노트/설정백업)은 그대로 유지됩니다.
- 성경 리더 절 선택 메뉴에 **‘이 본문으로 귀납적 연구 시작’** 진입점 추가.
- **본문 마킹 18종**(주어/동사/목적어/접속사 등)과 **구조 연결 9종**(주어↔동사 등). 모바일 단어 칩 다이얼로그 + ‘주어 → 동사 흐름’ 요약.
- **관찰 질문 템플릿 8종**, **단락 성격 태그 14종**.
- **해석 노트**(핵심 단어·평이한 의미·문맥 의미·본문 근거·관련 구절·해석 결론).
- **핵심주제 검증 체크리스트 5종**, **명제**(검토 상태 3종), **개요**(부모-자식 트리), **적용**(Material 3 DatePicker + 실천 토글).
- **리포트 내보내기**: Markdown 미리보기 · 복사 · 시스템 공유 · **PDF 공유** · **시스템 인쇄**.
- 해석·명제는 마킹/단락에 **명시적 본문 근거 링크**가 가능하며 카드에 색상 칩으로 시각화됩니다.
- **암호화 백업/복원**이 연구 데이터 전체(11개 테이블)를 포함합니다. 복원 시 ‘기존 study 데이터 덮어쓰기’ 토글 제공.

### 데이터 안정성

- Room DB **v1 → v5** 단계별 마이그레이션. 기존 사용자의 메모/북마크/읽기 기록/목표는 모두 보존됩니다.
- 마킹·단락 삭제 시 stale 링크 자동 정리(sweeper).
- v1↔v5 전구간 마이그레이션 자동 테스트(Room `MigrationTestHelper`).

### 정책

- 외부 AI API, 외부 서비스, 광고/분석 SDK 추가 없음.
- 모든 연구 데이터는 로컬 우선이며 사용자가 만든 백업 파일에만 포함됩니다.
