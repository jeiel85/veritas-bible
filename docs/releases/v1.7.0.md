## v1.7.0 — 본문 가독성·언어·연구 범위 UX 보강

### 핵심 변경

사용자 피드백 4건을 반영해 본문 읽기 경험과 연구 흐름을 한층 다듬었습니다.

### 신규 기능 및 변경

- **영어 모드에서 책 이름이 영어로**: `BibleViewModel` 이 DB 카탈로그(66권 한·영 매핑)를 메모리 캐시. 리더 헤더·드롭다운·메모 다이얼로그·연구 세션 헤더·세션 카드 모두 `appLanguage="EN"` 일 때 자동으로 `John / Genesis / Romans …` 로 노출됩니다.
- **본문 마킹 시각화 재설계**: 색상 배경 블록 → **타입별 색상 + 두꺼운 밑줄 + SemiBold** 로 변경. 한국어 본문 흐름이 끊기지 않고 자연스럽게 이어집니다.
- **구조 연결선 (Canvas overlay)**: 같은 절 안의 명시 link 는 본문 아래에 brace 곡선으로, 줄을 넘는 link 는 양쪽에 짧은 끝꼬리로 표시됩니다. 색상은 from 마킹의 타입 색을 따릅니다.
- **연구 범위 직접 선택(`여기부터` / `여기까지`)**: 새 `StudyCreateDialog` 로 두 anchor 카드를 따로 잡고, 각각에 대해 책 → 장 → 절 3단계 picker(`AssistChip` 단계 인디케이터 + LazyColumn / Grid)에서 직접 선택합니다. 시작 > 끝 자동 정렬 + 잘못된 범위 안내.
- **한글 개역 단락 ● 표시**: `scripts/build_bible_json.py` 가 영어 WEB USFM 의 `\p / \q / \pi / \pm …` 마커를 감지해 14,676개 절에 `pb: true` 를 부여했습니다. 리더와 연구 상세 본문 패널이 단락 시작 절 앞에 `●` 를 그려, 한국어 사용자에게 익숙한 단락 감각을 그대로 살립니다.

### 데이터 안정성

- Room DB **v5 → v6** 마이그레이션: `bible_verses.paragraphStart INTEGER NOT NULL DEFAULT 0`. 기존 사용자의 하이라이트/메모/연구 데이터는 모두 그대로 보존됩니다.
- `BibleDataPrepopulator.syncParagraphMarksIfNeeded` 가 첫 실행 시 9.7MB `bible.json` 의 `pb` 정보만 UPDATE 로 반영합니다.
- v5↔v6 마이그레이션 자동 테스트가 `StudyMigrationTest` 에 추가되어, v1 부터 v6 까지 전구간이 자동으로 검증됩니다.

### 정책

- 외부 AI API, 외부 서비스, 광고/분석 SDK 추가 없음. 모든 사용자 데이터는 로컬 우선.
