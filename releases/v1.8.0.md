## v1.8.0 — 본문 구조 분석 (직접 탭 마킹·연결)

### 핵심 변경

귀납적 성경연구의 손글씨 방식 — 본문 위에 직접 단어를 골라 주어·동사·핵심어를 표시하고, 주어→동사처럼 단어를 이어 본문을 하나의 구조로 보는 흐름 — 을 연구(Study) 세션 본문 패널에 직접 구현했습니다. 일반 리더는 읽기 전용으로 그대로 두고, 구조 분석은 연구 세션 안에만 넣었습니다.

(출시되지 않았던 v1.7.1 의 리더 다중 선택·하이라이트 다듬기도 본 릴리스에 함께 포함됩니다.)

### 신규 기능

- **본문 직접-탭 마킹**: 연구 본문에서 단어를 직접 탭하면 선택한 타입(주어·동사·목적어·접속사·핵심어)으로 마킹됩니다. 같은 단어를 다시 탭하면 해제.
- **단어-단어 연결**: 연결 모드에서 단어 A 탭 → 단어 B 탭 하면 주어↔동사 같은 구조 연결선이 본문 위에 그려집니다. 아직 마킹되지 않은 단어는 연결 타입에 맞춰 자동 마킹됩니다.
- **절을 넘는 연결 힌트**: 다른 절로 이어지는 연결은 정확한 선 대신 "다음 구절로 이어진다"는 아래방향 화살촉 힌트로 표시합니다.
- **읽기 / 마킹 / 연결 모드 바**: 본문 패널 상단에서 모드를 전환합니다. 읽기 모드에서는 탭이 비활성화되어 평소처럼 읽고 스크롤할 수 있습니다.

### 다듬기 (이전 v1.7.1 작업 포함)

- **리더 절 다중 선택**을 그대로 연구 범위로 전달.
- 절 단위 하이라이트를 **왼쪽 색상 막대 + 옅은 배경**으로 정리해 본문 흐름 가독성 보강.

### 데이터 안정성

- 데이터베이스 스키마 변경 없음 (Room v6 유지, 마이그레이션 없음). 기존 마킹·연결·메모·하이라이트·연구 세션은 모두 그대로 보존됩니다.

### 정책

- 외부 AI API, 외부 서비스, 광고/분석 SDK 추가 없음. 모든 사용자 데이터는 로컬 우선.
