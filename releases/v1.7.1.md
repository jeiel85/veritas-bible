## v1.7.1 — 리더 다중 선택·하이라이트 다듬기

### 핵심 변경

v1.7.0 후속 — "연구 범위는 리더에서 직접 절을 선택해서 잡고 싶다"는 사용자 피드백을 반영해, 다이얼로그 안 picker로만 가능하던 흐름을 리더 본문에서 곧장 잡는 흐름으로 보강했습니다.

### 신규 기능 및 변경

- **리더에서 절 다중 선택**: 한 절 탭 = 단일 선택 (anchor), 다른 절 탭 = 범위 잡힘 (anchor↔target 자동 정렬). 같은 절 재탭으로 해제. 챕터·책이 바뀌면 선택은 자동으로 초기화됩니다.
- **선택 팔레트가 범위 표시**: "창세기 1:3-1:7 (5개 절)" 식 라벨. 단일 선택일 땐 "다른 절을 탭하면 범위가 잡힙니다." 힌트로 다중 선택 발견성을 높였습니다.
- **연구 범위 자동 전달**: "이 본문으로 귀납적 연구 시작" 버튼이 선택 범위를 그대로 `StudyCreateDialog` 의 anchor 두 개로 채워, 사용자가 picker 안으로 다시 들어가지 않아도 됩니다. 필요하면 anchor 카드로 picker 열어 조정 가능.
- **일괄 동작**: 색상 하이라이트·해제·공유·복사는 선택된 모든 절에 한 번에 적용됩니다. 메모는 의미상 단일 절에만 활성.
- **절 단위 하이라이트 시각화 개선**: 전체 배경 박스 → **왼쪽 3dp 색상 막대 + 옅은 배경**. v1.7.0 마킹 의도("본문 흐름이 끊기지 않게")를 리더 화면에도 일관 적용했습니다.

### 데이터 안정성

- 데이터베이스 스키마 변경 없음 (Room v6 유지). 기존 메모·하이라이트·연구 세션은 모두 그대로 보존됩니다.

### 정책

- 외부 AI API, 외부 서비스, 광고/분석 SDK 추가 없음. 모든 사용자 데이터는 로컬 우선.
