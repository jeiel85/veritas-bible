## v1.8.1 — 구조 분석 직접-탭 단순화

### 핵심 변경

v1.8.0 의 본문 직접-탭 구조 분석에서 **타입 선택 단계를 제거**했습니다. 단어 종류(주어·동사 등)를 매번 명시적으로 고르는 것은 오히려 마찰이라는 사용자 피드백을 반영 — 그냥 탭으로 구조를 한눈의 그림처럼 그려나가는 흐름으로 다듬었습니다.

### 변경 사항

- **마킹 모드**: 타입 칩 제거. 단어를 탭하면 표시되고, 다시 탭하면 해제됩니다. (종류는 묻지 않음)
- **연결 모드**: 연결 타입 칩 제거. 단어 두 개를 탭하면 연결되며, **역할은 탭 순서로 암묵 결정**됩니다 — 첫째=주어, 둘째=동사. 그래서 연결하면 주어·동사 색이 자동으로 입혀집니다.
- 본문 패널은 **읽기 / 마킹 / 연결** 3개 칩 + 한 줄 안내만 남겨 더 가벼워졌습니다.
- 세밀한 타입 지정이 필요하면 기존 정밀 편집 다이얼로그를 fallback 으로 그대로 사용할 수 있습니다.

### 데이터 안정성

- 데이터베이스 스키마 변경 없음 (Room v6 유지, 마이그레이션 없음). 이전에 만든 마킹·연결·메모·연구 세션은 모두 그대로 보존됩니다.
