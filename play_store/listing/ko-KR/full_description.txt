Veritas Bible은 인터넷 연결 없이 사용할 수 있는 한국어·영어 병행 성경 연구 앱입니다.

[ 핵심 기능 ]
• 한국어(개역 1910, 공유저작물) + 영어(World English Bible, 공유저작물) 66권 전체 본문 내장
• 빠른 키워드 검색 (한·영 동시 검색)
• 절 단위 하이라이트와 색상 분류
• 절마다 개인 묵상 노트 작성 — AES 암호화 후 기기 내부에만 저장
• 일일 읽은 절·장 수 자동 기록과 통계 차트
• 사용자가 설정하는 독서 목표 진행률
• 비밀번호로 보호된 백업/복원 (텍스트로 내보내기·가져오기)
• 시스템·라이트·다크 테마, 한국어·영어 UI 전환

[ 개인정보 ]
• 모든 데이터는 기기에만 저장됩니다.
• 광고 SDK, 분석 SDK, 외부 서버 통신이 없습니다.
• 백업 파일은 사용자가 직접 내보낼 때만 외부로 나갑니다.
